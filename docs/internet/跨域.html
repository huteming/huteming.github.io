跨域

同源策略限制以下几种行为：

  • Cookie、LocalStorage 和 IndexDB 无法读取
  • DOM 和 Js 对象无法获得
  • AJAX 请求不能发送

跨域解决方案

  1. 跨域资源共享（CORS）
  2. 代理跨域（比如：nginx）
  3. jsonp 跨域
  4. WebSocket 协议跨域
  5. postMessage 跨域
